## Review Conditions Preserved By The Proposal

1. The normal form is computed once. Every friendly variable is an accessor
   application to one terminal contextual slot; no variable receives an
   independent coherence payload.
2. The contextual endpoint fallback is dynamically scoped and restored in a
   `finally` block. The historical single-fibre chain path remains the first
   path and retains its exact output and diagnostics.
3. A recovered endpoint records identity independently of chain length. A
   contextual pair or application must never masquerade as the bare terminal
   identity merely because it has no syntactic chain array.
4. Structural and dependent prerequisites from contextual endpoint
   compilation are retained in evidence and runtime qualification. They are
   not silently discarded when the point factorer recovers the whole
   transformation.
5. Synthesis from the body does not weaken checking: the body must already be
   a typed indexed Hom, its contextual endpoint must compile from the terminal
   source family, and the factored result must be closed and have exactly the
   same source/target family and functors.
6. The one all-six synthetic-pair timeout remains diagnostic only. The
   implementation must avoid repeated normal-form construction, while the
   proposal neither promises a performance graduation nor narrows semantic
   finite-genericity to a fixed arity.
