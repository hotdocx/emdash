## First Feasibility Question

Can the source tip's complete final profile owner typecheck against main's
already-stable contravariant ladder, and which dependency prevents it if not?
This is an isolated compatibility probe, not a proposed wholesale production
replacement. Preserve the full file and internal rule positions. Compare an
unchanged main profile control, then append focused classified positives and
ambient controls. A passing owner with global main cuts still present cannot
establish lax noncollapse or completion of the migration.

The first acceptance consumers are the existing profile reviewer and main's
diagram-evaluation/ordinary Hom-comparison operations. Their strictness
admission must be justified at the actual named owner; no evidence constant
is introduced merely to make those operations fit.

Before promoting any rules, inventory warning families and exact source
changes, preserve the main core control, and check the first new-main
consumer. If the final profile cannot stand on main's unchanged endpoints,
record the failure and sequence the smallest required whole-owner change.

Dependency experiment (`API-Q02`): in a full copy of main's nucleus,
remove only the capped ambient composition cut and its generic
`fapp1_comp_path` theorem, preserving their exact source position and all
other rules. This deliberately incomplete migration locates the first real
dependency. The remaining whole cuts make a success insufficient evidence of
ambient noncollapse. Do not promote the copy or repair failures by restoring
a detached composition-law capability.

the need for the post-profile action dependency move rather than an early

owners would already pass after repairing this first dependency.

Selected next slice: the ordinary whole strictness property, its derived
capped evidence and opaque classifier boundary, followed by strict mapped
equivalence/isomorphism action and a named-evaluation/main Hom-comparison
consumer. The first subtranche may strengthen the current property before
replacing its existing facade; it must not claim the global migration is
complete or introduce any historical detached-law scaffold. Promote only
