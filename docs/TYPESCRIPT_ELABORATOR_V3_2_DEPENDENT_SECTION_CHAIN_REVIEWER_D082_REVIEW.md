## Independent Review

The frozen proposal promotes completed semantic behavior into an existing
consumer. D-081 already proves that the direct and text surfaces accept

```text
lambda^n k : K. GG[k](FF[k](s[k]))
```

through one recursive factorer and existing `comp_fapp0`/`piapp1_fapp0`
owners. Changing the reviewer fixture from one layer to two therefore needs no
parser, resolver, categorical-surface, Core, checker, evaluator, runtime,
transfer, or active-kernel branch.

Keeping the `indexed-section-composition` preset ID is the correct product
choice. The new source demonstrates the newly graduated capability without
increasing the public preset count or adding another UI route. Adding
`Q : Catd K` and `GG : Functord D Q` to both the text environment and direct
mirror supplies exactly the adjacent classifier required by D-081. Checking
against `Q` exercises the outer layer instead of accepting a dead or ignored
head.

The existing reviewer architecture provides strong equivalence oracles. Every
preset is executed through the text adapter and compared with its direct
`CoreCategoricalProgram` construction for explicit Core, inferred and expected
classifiers, structural prerequisites, and computation. The expected-mode UI
formats the target field generically, so changing its literal classifier from
`D` to `Q` is presentation data rather than a new display algorithm. The
deep-freeze and all-preset inventory checks remain applicable unchanged.

One incompatible-chain edit is the right negative. For example, applying
`GG[k]` directly to `s[k]` violates the exact intermediate family even though
all names are in scope. Rejection demonstrates that the reviewer has not
become an untyped nested-application demo.

The public-document synchronization is bounded and necessary. The source
already owns twelve preset IDs, while the external-review document and the
introductory fixture paragraph still say ten and omit two existing rows. This
is stale user-facing inventory, not historical evidence that should be
preserved. Updating only those two current consumer documents and the indexed
source avoids rewriting the book's useful one-layer base example or touching
completed architecture plans.

The revision and boundary changes are honest. One new supported sentence may
claim arbitrary finite *rigid indexed-section action chains*, because D-081
establishes structural recursion and internal action for exactly that grammar.
It must retain the exclusions for arbitrary point bodies, transport,
dependency/variance DAGs, and unrestricted displayed coherence.

Focused reviewer tests, root typecheck, changed-file lint, the standalone
browser production build, and diff hygiene are proportional. The semantic
engine and active kernel are unchanged, and D-081's focused semantic and
bounded-kernel evidence is recent, so another multi-minute root aggregate or
kernel check would add no relevant evidence.
