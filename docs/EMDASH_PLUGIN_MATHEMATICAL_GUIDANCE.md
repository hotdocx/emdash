# Mathematical Interpretation For Emdash Plugins

This is the shared source for the packaged local and cloud skill references.
The transport changes where a program runs, not its mathematical authority.

The pilot computes exact rational polynomials with ordered variables and an
ideal-membership query. Coefficients and exponents use exact strings, such as
`"1/2"` and `"3"`. A membership computation records actual coefficients and a
remainder. Its checked coefficient identity is exact arithmetic evidence.

Given a positive retained relation `g = a1*f1 + ... + an*fn`, native reuse forms
the row `D = (f1,...,fn,g)` and column `s = (a1,...,an,-1)`, constructs the whole
two-step finite free complex and applies its upper map to one. It checks
`D*s = 0` and preserves the supplied coefficient choice. This does not assert
that the relation generates the whole kernel, or that the complex is exact
or a resolution. Reject stale or invalid retained data; do not silently
recompute another witness to make reuse succeed.

The optional internal route assembles transparent Core definitions for the
complex and a further action from the actual matrices, relative to one
explicit computed-equation assumption. Record the adoption reason and state
that assumption status when reporting the mathematical result. This route
does not satisfy a request for a proof without that assumption. It does not
add a standalone TypeScript projection-reduction qualification.

The native image at one is distinct from the internal action on a supplied
symbolic rank-one vector `a`. For the default column `(-x, 1, -1)`, the action
is `a ↦ (-x*a, a, -a)` and its value at one is the column. Do not identify the
column with the value on every argument or claim the internal expression was
normalized to those coordinates.

The current internal interpretation accepts integer polynomials in a supplied
commutative ring. Exact rational native computation remains useful when that
interpretation rejects a coefficient. Do not silently clear denominators or
replace the mathematical input.

The two-variable curve view is an approximate real-locus sample. It can miss
components, tangencies or singularities and does not certify topology. Keep
exact results useful independently of plot availability.

A process exit code, controller receipt, diagram or cached result is not a
mathematical proof. Check source identity and use the selected mathematical
owner's result, assumptions and qualification. Computation and visualization
do not require a proof goal or adoption; choose formal work when the user's
mathematical task calls for it.
